# Лабораторная работа №3: Стек и очередь

## Вариант: Система обработки задач (Queue)
**Цель работы:** Реализация структуры данных «Очередь» на базе принципа FIFO (First In — First Out) для управления списком задач.

##  Реализованный функционал:
1. **Класс Task:** Модель задачи, содержащая `id`, `description` (описание) и `priority` (приоритет).
2. **Обязательная часть (Методы очереди):**
   - `enqueue(task)` — добавление новой задачи в конец очереди.
   - `dequeue()` — извлечение и удаление первой задачи из начала очереди.
   - `front()` — просмотр задачи в начале очереди без удаления.
   - `is_empty()` — проверка очереди на пустоту.
3. **Вариативная часть:**
   - `find_by_id(task_id)` — линейный поиск задачи внутри текущей очереди по её уникальному идентификатору без нарушения порядка элементов.

##  Тестирование
Программа поддерживает интерактивный ввод идентификатора в консоли для демонстрации работы вариативной части (поиска), после чего поочередно обрабатывает все задачи в порядке их поступления.
