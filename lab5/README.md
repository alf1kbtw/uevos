# Лабораторная работа №5: Двоичные деревья поиска (BST)

**Цель работы:** Реализация иерархической структуры данных «Бинарное дерево поиска» для эффективного хранения, поиска и модификации целых чисел с использованием рекурсивных подходов.

## Реализованный функционал:
1. **Обязательная часть:**
   - `insert(root, value)` — рекурсивная вставка элементов с автоматическим распределением: меньшие значения уходят в левое поддерево, большие — в правое.
   - `search(root, target)` — проверка наличия элемента в дереве со средней скоростью $O(\log n)$. Возвращает логическое значение (`True`/`False`).
   - `inorder(root)` — симметричный обход дерева (DFS), собирающий все хранящиеся числа в отсортированном по возрастанию порядке.
2. **Вариативная часть (Задача №1):**
   - `delete(root, value)` — алгоритм удаления узла с сохранением инварианта BST. Корректно обрабатывает три сценария удаления:
     - Лист (узел без потомков).
     - Узел с одним потомком (подтягивание ветви).
     - Узел с двумя потомками (поиск минимального элемента в правом поддереве для замещения).

## Демонстрация работы
Программа снабжена текстовым интерактивным интерфейсом. При запуске дерево автоматически балансируется базовым набором значений, предоставляя возможность протестировать вставку, поиск, удаление и сортировку в реальном времени через консоль.
