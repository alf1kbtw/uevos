# Лабораторная работа №2: Динамические структуры данных (Двусвязный список)

## Вариант: Маршрут автобуса
**Цель работы:** Реализация линейного двусвязного списка для моделирования автобусного маршрута с функциями расчёта времени, прогнозирования положения и построения обратного пути.

##  Реализованный функционал:
1. **Создание маршрута:** Динамическое добавление автобусных остановок (узлов) в конец списка. Каждый узел хранит название, координаты $(X, Y)$ и время движения до следующей точки.
2. **Расчёт времени:** Автоматический подсчёт суммарного времени движения от начальной до конечной остановки.
3. **Прогнозирование:** Определение того, на какой остановке окажется автобус через $N$ остановок после контрольной точки. Реализована проверка на случай выхода за пределы маршрута (конечная остановка).
4. **Обратный маршрут:** Вывод названий остановок в обратном порядке посредством обхода списка с конца с использованием указателей `prev`.
5. **Вариативная часть (Задача №4):** Автоматическая генерация и сохранение подробного структурированного отчёта по маршруту в текстовый файл `bus_line_10_report.txt`.

##  Запуск и тестирование
Код программы содержится в файле `main.py`. При запуске в консоль выводятся результаты тестирования всех ключевых функций, а также создаётся файл отчёта.
