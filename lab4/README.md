# Лабораторная работа №4: Словари и хэш-таблицы (Map)

## Вариант: Сокращатель ссылок
**Цель работы:** Реализация сервиса сокращения и поиска ссылок с использованием ассоциативного массива (структуры данных Map/Dictionary) для обеспечения константного времени доступа $O(1)$.

## Реализованный функционал:
1. **Обязательная часть:**
   - Добавление новой ссылки с автоматической генерацией случайного 4-значного буквенно-цифрового кода.
   - Получение исходной длинной ссылки по предоставленному короткому коду за среднее время $O(1)$.
   - `is_code_exists(code)` — проверка существования ключа (короткого кода) в хэш-таблице.
   - `print_all_urls()` — форматированный вывод всей базы данных соответствий.
2. **Вариативная часть (Задача №1):**
   - Реализована строгая проверка уникальности при попытке пользователя создать кастомный короткий код. Если код уже занят, система блокирует транзакцию, предотвращая перезапись данных и гарантируя бесколлизионность пользовательского ввода.

## Тестирование
Программа представляет собой консольное приложение с интерактивным меню. Первоначально база данных инициализируется двумя дефолтными значениями, после чего администратор может тестировать генерацию кодов, поиск и валидацию дубликатов в реальном времени.
